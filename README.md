A tiny Node program that writes an original short poem about stopping — about restraint, the unsent message, and the quiet power of leaving white space — to `entry.txt` when it runs.

## Run it

```sh
node --experimental-strip-types main.ts
```

Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written (defaults to `/output`).
